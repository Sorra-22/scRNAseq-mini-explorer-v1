# scRNA-seq Mini-Explorer

## Overview
Lightweight Streamlit-based app for interactive exploration of scRNA-seq datasets using Scanpy.

## Features
- Load AnnData (.h5ad)
- QC filtering
- PCA / UMAP / Leiden clustering
- Marker gene identification
- Gene expression visualization
- Download filtered data

## Requirements
- Python ≥ 3.9
- ≤ 8 GB RAM
- CPU-only
